§1 Overview

Complexity Across Primes

The Gregorian leap-year count Λ(Y) has different linear complexity depending on the prime modulus p. This chart shows how L(Λ) mod p varies across the first 50 primes not dividing 400.

§4 Theory

Theoretical Foundations

The linear complexity is computed via generating functions and root-counting on rational functions.
Theorem Formula / Result
A (Staircase) g_n(Y) = ⌊Y/n⌋ mod p has complexity n+1
B (Upper Bound) L(L_{a,b,c}) ≤ abc+1
C (Exact) L(L_{a,b,c}) = abc+1 − (ab−a)·[p|c−1] − a·[p|bc−c+1]
D (General) For arbitrary moduli: M+1 − Σ φ(d)·[σ_d=0] − ε
