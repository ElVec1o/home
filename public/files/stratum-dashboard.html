Stratum Live Dashboard

The interactive streaming dashboard shows Top-K values updating in real time with cyan bars, pulse animations, and an SSE event ticker.

To run the live dashboard locally from the Stratum repository:

cd Stratum
./scripts/run_server.sh
# Then open http://127.0.0.1:8080/

The dashboard features:

  • Real-time Top-K streaming updates
  • Buttons to ingest 1k / 100k / 1M events
  • Auto-ingest toggle for continuous streaming
  • Live SSE event feed with delta encoding
  • Tail latency metrics and throughput tracking
