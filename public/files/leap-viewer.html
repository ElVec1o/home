Linear Complexity of Nested Leap-Year Sequences

Vico Bonfioli · 2026-09-05
GitHub Repo Dashboard

Abstract

For a positive integer n and a prime p, the staircase sequence g_n(Y) = floor(Y/n) mod p is a linear recurring sequence over F_p with minimal polynomial (x-1)(x^n-1) and linear complexity n+1.

We determine the linear complexity of every F_p-linear combination of such sequences: it is M+1 minus a sum of Euler-φ terms, one for each divisor d of M = lcm(m_i) at which a certain linear form in the coefficients vanishes modulo p.

For the nested leap-correction sequence L_{a,b,c} = g_a - g_{ab} + g_{abc}, the finite-field model of a calendar with leap rule "every a years, except every ab, except every abc", this specializes to:

L(L_{a,b,c}) = abc+1 - (ab-a)·[p | c-1] - a·[p | bc-c+1]

For the Gregorian rule (a,b,c)=(4,25,4) the leap-year count Λ(Y) therefore has linear complexity exactly 401 modulo every prime p ∤ 400 except p=3 (complexity 305) and p=97 (complexity 397).

Key Results

Theorem A

Single Staircase: The sequence g_n has minimal polynomial (x-1)(x^n-1) and linear complexity n+1.

Theorem C

Nested Sequence: For L_{a,b,c}, the complexity depends on whether p divides c-1 or bc-c+1.

Gregorian Calendar

Leap-Year Count: Complexity is exactly 401 for the Gregorian rule, except for p=3 and p=97.

The Problem

The weekday of a Gregorian date is determined by Y modulo 400 and by the day-of-year; the only irregular ingredient is the number of leap years before year Y:

Λ(Y) = floor(Y/4) - floor(Y/100) + floor(Y/400)

Reduced modulo 7, Λ is a periodic sequence over F_7 and therefore a linear recurring sequence. This note determines its linear complexity: the length of the shortest linear feedback shift register that generates it.

Methodology

The standard approach for linear recurring sequences: write the generating function as a reduced rational function and read the linear complexity off the degree of the denominator.

For staircase sequences, the generating function is:

∑_{Y≥0} floor(Y/n)·x^Y = (x^n)/((1-x)(1-x^n))

All proofs are elementary, by counting common roots of the numerator and denominator.
